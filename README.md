# 🚦 Rate Limit Service

A Node.js API service built with Express, Redis, and MongoDB that demonstrates rate limiting and request caching. Useful for preventing abuse and ensuring fair usage of APIs.

---

## 📦 Tech Stack

- **Node.js**
- **Express**
- **MongoDB + Mongoose**
- **Redis**
- **JWT Authentication**

---

## 🚀 Features

- ✅ Rate limiting using Redis (per IP or user)
- ✅ Authentication via JWT
- ✅ Caching product data
- ✅ MongoDB integration for persistent data
- ✅ Error handling and modular structure
